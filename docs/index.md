# Harmonized Calculation Method for Africa (HCM4A) for Mobile Service

The HCM4A-MS software is a tool designed to assist Administrations in performing interference calculations according to the HCM4A Agreement for Mobile Service.

The documentation consists of two main parts:

1.  **Graphical User Interface (GUI) Program Description**: The GUI program for Mobile Service, `HCM4AMobileService`, provides tools for interference assessment between mobile stations, cross-border range calculations, and x-km line calculations, adhering to Annex 2A of the Agreement for MS. For detailed instructions on using this GUI, refer to the [Mobile Service - Graphical User Interface Guide](hcm4a_ms_gui_guide.md).

2.  **Source Code Compilation Guide**: For users who wish to compile the HCM4A-MS software from source, this guide provides step-by-step instructions for setting up the development environment, compiling the Mobile Service calculation library, and building the `HCM4AMobileService` GUI program. Refer to the [Mobile Service - Source Code Compilation Guide](hcm4a_ms_compilation.md) for more details.
